它的核心问题是：

当数据维度 $$n$$ 很高、样本数 $$m$$ 不够多时，直接拟合一个完整高斯分布的协方差矩阵会很困难。Factor Analysis 用低维 latent variable 来解释高维数据的主要相关结构。

CS229 Note 9 总结：Factor Analysis

1. 为什么需要 Factor Analysis？

假设数据是：

x(i)∈Rn

如果我们想用一个多元高斯建模：

x∼N(μ,Σ)

那么需要估计：

μ

和：

Σ

其中：

Σ∈Rn×n

是协方差矩阵。

普通最大似然估计是：

μ=1m∑i=1mx(i)Σ=1m∑i=1m(x(i)−μ)(x(i)−μ)T

但是当：

n≫m

时，问题来了。

因为样本点最多只张成一个低维子空间，估计出来的协方差矩阵：

Σ

很可能是 singular matrix。

也就是说：

Σ−1

不存在。

而高斯密度中需要：

Σ−1

和：

|Σ|

所以普通 full covariance Gaussian 就没法稳定建模。CS229 notes9 开头也正是从这个问题出发：当数据维度 $$n$$ 远大于样本数 $$m$$ 时，直接估计高斯协方差会导致奇异矩阵问题。

2. 直接限制协方差矩阵的方法

为了避免完整协方差矩阵太难估计，可以限制：

Σ

的形式。

2.1 Diagonal Covariance

第一种方式是假设：

Σ

是对角矩阵：

Σ=[σ120⋯0 0σ22⋯0 ⋮⋮⋱⋮ 00⋯σn2]

这相当于假设不同维度之间不相关。

优点：

缺点：

例如图片、语音、传感器特征里，不同维度之间往往高度相关，对角协方差太弱。

2.2 Spherical Covariance

更强的限制是：

Σ=σ2I

这表示每个维度方差一样，并且不同维度不相关。

这对应高斯密度的等高线是圆形或高维球形。

优点：

缺点：

3. Factor Analysis 的核心思想

Factor Analysis 想做的是：

不直接估计完整的 $$n\times n$$ 协方差矩阵，而是假设高维数据由低维 latent factors 线性生成，再加上独立噪声。

也就是说，高维观测：

x∈Rn

背后有一个低维隐藏变量：

z∈Rk

其中：

k<n

这个：

z

就是 latent factor。

模型假设：

z∼N(0,I)x|z∼N(μ+Λz,Ψ)

等价地写成：

x=μ+Λz+ϵ

其中：

ϵ∼N(0,Ψ)

并且：

z

和：

ϵ

独立。

这里：

Λ∈Rn×k

叫 factor loading matrix。

Ψ∈Rn×n

是对角矩阵，表示每个观测维度自己的独立噪声。

CS229 notes9 中正是用这个形式定义 factor analysis：$$z\sim N(0,I)$$，$$x|z\sim N(\mu+\Lambda z,\Psi)$$，其中 $$\Psi$$ 是对角矩阵。

4. Factor Analysis 的直觉

你可以这样理解：

例如：

每个观测变量都可能由少数 latent factors 线性组合生成。

Factor Analysis 的目标是：

用少数 latent factors 解释高维变量之间的相关性。

5. Factor Analysis 如何表达协方差？

由模型：

x=μ+Λz+ϵ

其中：

z∼N(0,I)ϵ∼N(0,Ψ)

且二者独立。

先求均值：

E[x] ==== # E[\mu+\Lambda z+\epsilon] # \mu+\Lambda E[z]+E[\epsilon] \mu

再求协方差：

Cov(x)=====================Cov(Λz+ϵ)

因为：

z

和：

ϵ

独立，所以交叉项为 0。

于是：

Cov(x)=====================ΛCov(z)ΛT+Cov(ϵ)

由于：

Cov(z)=ICov(ϵ)=Ψ

所以：

Cov(x)=====================ΛΛT+Ψ

因此：

x∼N(μ,ΛΛT+Ψ)

这就是 Factor Analysis 最重要的结论。

CS229 notes9 也推导出联合高斯中的 $$\Sigma_{xx}=\Lambda\Lambda^T+\Psi$$，并得到边缘分布 $$x\sim N(\mu,\Lambda\Lambda^T+\Psi)$$。

6. 为什么这比 full covariance 好？

完整协方差矩阵：

Σ

有大约：

n(n+1)2

个自由参数。

当：

n

很大时，参数量是：

O(n2)

而 Factor Analysis 中：

Λ∈Rn×k

有：

nk

个参数。

Ψ

是对角矩阵，有：

n

个参数。

总共大约：

nk+n

个参数。

如果：

k≪n

那么参数量远少于 full covariance。

同时：

ΛΛT

又能表达维度之间的相关性。

所以 Factor Analysis 处于两者之间：

模型 协方差形式 表达能力 参数量
Spherical Gaussian $$\sigma^2 I$$ 很弱 1
Diagonal Gaussian $$\Psi$$ 只能建模各维方差 $$n$$
Factor Analysis $$\Lambda\Lambda^T+\Psi$$ 能建模低秩相关结构 $$nk+n$$
Full Gaussian $$\Sigma$$ 最强 $$O(n^2)$$

一句话：

Factor Analysis 用 low-rank covariance plus diagonal noise 来近似 full covariance。

7. Joint Gaussian：为什么要推联合分布？

为了使用 EM，我们需要计算：

p(z|x)

也就是 E-step 中 hidden variable 的 posterior。

而在 Factor Analysis 中：

z

和：

x

都是高斯线性变换，所以：

[z x]

服从联合高斯。

由：

z∼N(0,I)x=μ+Λz+ϵ

可以得到：

[z x]∼N([0 μ],[IΛT ΛΛΛT+Ψ])

这个式子非常重要，因为它让我们可以用高斯条件分布公式算：

p(z|x)

8. 高斯条件分布公式

如果：

[x1 x2]∼N([μ1 μ2],[Σ11Σ12 Σ21Σ22])

那么：

x1|x2∼N(μ1|2,Σ1|2)

其中：

μ1|2=========μ1+Σ12Σ22−1(x2−μ2)Σ1|2============Σ11−Σ12Σ22−1Σ21

这就是 note9 中间复习 marginal and conditional distributions of Gaussians 的原因：后面 E-step 要直接用这个公式。

9. E-step：求 $$p(z|x)$$

在 Factor Analysis 里，E-step 要计算：

Qi(z(i))============p(z(i)|x(i);μ,Λ,Ψ)

由前面的联合高斯分布可以得到：

z(i)|x(i)∼N(μz|x(i),Σz|x)

其中：

μz|x(i)===============ΛT(ΛΛT+Ψ)−1(x(i)−μ)Σz|x============I−ΛT(ΛΛT+Ψ)−1Λ

所以 E-step 的作用是：

对每个样本，估计它背后的 latent factor $$z^{(i)}$$ 的后验分布。

注意，这里不是只估计一个点：

E[z(i)|x(i)]

还需要估计后验协方差：

Cov(z(i)|x(i))

CS229 notes9 在 E-step 中给出 $$z^{(i)}|x^{(i)}$$ 的条件高斯均值和协方差，分别对应上面两个公式。

10. M-step：更新 $$\Lambda,\mu,\Psi$$

M-step 是固定 E-step 得到的：

Qi(z(i))

也就是：

p(z(i)|x(i))

然后最大化：

∑i=1mEz(i)∼Qi[log⁡p(x(i),z(i);μ,Λ,Ψ)]

对于 Factor Analysis，最核心的是更新：

Λ

它的形式类似最小二乘中的 normal equation。

10.1 更新 $$\Lambda$$

M-step 中：

Λ

的更新为：

Λ=======(∑i=1m(x(i)−μ)E[z(i)T|x(i)])(∑i=1mE[z(i)z(i)T|x(i)])−1

因为：

E[z(i)|x(i)]==================μz|x(i)

所以：

E[z(i)T|x(i)]===================μz|x(i)T

并且：

E[z(i)z(i)T|x(i)]==========================μz|x(i)μz|x(i)T+Σz|x

因此：

Λ=======(∑i=1m(x(i)−μ)μz|x(i)T)(∑i=1mμz|x(i)μz|x(i)T+Σz|x)−1

这就是 note9 里面最重要的 M-step 更新之一。CS229 notes9 也强调：这个公式和最小二乘 normal equation 很像，但关键区别是这里必须使用 $$E[zz^T]$$，不能只用 $$E[z]E[z]^T$$。

10.2 为什么像最小二乘？

因为 Factor Analysis 的生成式是：

x=μ+Λz+ϵ

如果我们真的知道每个样本的：

z(i)

那么估计：

Λ

就很像线性回归：

x−μ≈Λz

最小二乘解的结构会类似：

Λ=======(∑i(x(i)−μ)z(i)T)(∑iz(i)z(i)T)−1

但问题是我们不知道：

z(i)

所以 EM 用后验期望替代：

z(i)

和：

z(i)z(i)T

也就是：

E[z(i)|x(i)]

和：

E[z(i)z(i)T|x(i)]

10.3 最容易犯的错误

很多人会以为：

E-step 只需要算 $$E[z|x]$$，然后把它当成真正的 $$z$$ 代入 M-step。

这是错的。

因为 M-step 中会出现：

E[zzT|x]

而不是：

E[z|x]E[z|x]T

二者差一个协方差项：

E[zzT|x]=========E[z|x]E[z|x]T+Cov(z|x)

也就是：

E[zzT|x]=========μz|xμz|xT+Σz|x

这正是 note9 特别强调的地方：在 Factor Analysis 的 EM 中，M-step 必须考虑 posterior covariance，不能只使用 hidden variable 的均值估计。

11. 更新 $$\mu$$ 和 $$\Psi$$

11.1 更新 $$\mu$$

μ

的更新比较简单：

μ=1m∑i=1mx(i)

也就是样本均值。

这个值可以先算好，不需要每轮都变化。

11.2 更新 $$\Psi$$

Ψ

是对角矩阵，表示观测噪声的协方差。

M-step 中会先计算一个矩阵：

Φ

然后令：

Ψii=Φii

也就是只取：

Φ

的对角元素。

直觉上：

Ψ

表示的是：

用 latent factor 解释完之后，每个观测维度剩下的独立残差方差。

因为 Factor Analysis 假设噪声：

ϵ

各维独立，所以：

Ψ

必须是 diagonal matrix。

12. Factor Analysis 和 PCA 的关系

Factor Analysis 和 PCA 都是在做 latent low-dimensional representation，但出发点不同。

角度 PCA Factor Analysis
类型 几何/线性代数方法 概率生成模型
目标 找最大方差方向 用 latent factors 解释 covariance
噪声模型 通常不显式建模 显式建模 diagonal noise $$\Psi$$
latent variable 投影坐标 高斯 latent variable $$z$$
参数估计 特征值/SVD 最大似然/EM
输出 principal components factor loading matrix $$\Lambda$$

简单理解：

如果 Factor Analysis 中噪声满足：

Ψ=σ2I

并且取某些特殊设定，就和 Probabilistic PCA 很接近。

但标准 Factor Analysis 允许：

Ψ

是任意对角矩阵，因此不同维度可以有不同噪声方差。

13. Factor Analysis 和 GMM 的关系

GMM 中 latent variable 是离散的：

z∈1,2,…,k

表示样本来自哪个 component。

Factor Analysis 中 latent variable 是连续的：

z∈Rk

表示样本背后的低维连续因子。

模型 latent variable 含义
GMM 离散 $$z$$ 第几个 Gaussian component
Factor Analysis 连续 $$z$$ 低维 latent factor

所以两者都用 EM，但 E-step 形式不同。

GMM 的 E-step 是：

P(z=j|x)

Factor Analysis 的 E-step 是：

p(z|x)

也就是一个连续高斯分布。

16. 最容易卡住的地方

卡点 1：Factor Analysis 到底在干什么？

它不是普通降维算法，而是一个概率生成模型。

它假设：

x

是由低维：

z

生成的：

x=μ+Λz+ϵ

所以它是在用低维因子解释高维数据的相关结构。

卡点 2：为什么需要 EM？

因为：

z

是 latent variable。

如果知道：

z

估计：

Λ

就是线性回归。

但我们不知道：

z

所以 E-step 先估计：

p(z|x)

M-step 再用这个后验分布更新参数。

卡点 3：为什么不能只用 $$E[z|x]$$？

因为 M-step 里会出现二阶项：

E[zzT|x]

它等于：

E[z|x]E[z|x]T+Cov(z|x)

所以必须考虑 posterior uncertainty。

这点是 note9 最重要的细节之一。

卡点 4：$$\Lambda\Lambda^T+\Psi$$ 怎么理解？

ΛΛT

表示由低维 latent factors 造成的相关结构。

Ψ

表示各维自己的独立噪声。

所以：

ΛΛT+Ψ

就是：

这正是 Factor Analysis 比 diagonal Gaussian 更强、比 full Gaussian 更省参数的地方。

18. 一句话总结 note9

CS229 note9 的核心是：

Factor Analysis 用低维高斯 latent variable 线性生成高维观测数据，从而把高维协方差建模为 $$\Lambda\Lambda^T+\Psi$$。它既能表达特征之间的相关结构，又避免直接估计完整协方差矩阵；由于 latent factor $$z$$ 不可观测，因此使用 EM 来估计参数。

中文理解就是：

高维数据的相关性往往来自少数潜在因素。Factor Analysis 假设这些潜在因素先生成，再经过线性映射加噪声形成观测数据；学习时看不见潜在因素，所以用 EM 反复估计它们并更新模型。
